# Body Count for Mac

Signed and notarised Body Count installers and Sparkle metadata are stored here.

- Current feed: `appcast.xml`
- Immutable installers: `releases/VERSION-BUILD/`
- Source repository: `sideways-living/body-count`
- Source release tags: `vVERSION`

This directory contains no Body Count source code, signing keys, credentials, user vaults, diagnostics, or other private data.
