# IVO Evidence 0.1.1

## New Features

- Automatic update checks and signed Sparkle update support through GitHub Releases.
- A What's New summary that appears once for each installed app version.
- Release notes grouped into New Features, Bug Fixes, and General Improvements.

## Bug Fixes

- Stabilised the complete Swift Testing gate for file-heavy evidence tests.
- Hardened beta archive metadata handling for strict macOS signature verification.

## General Improvements

- Established beta semantic versioning from 0.1.1 toward the 1.0 release.
- Added repeatable GitHub release, appcast, build-number, and update-signing tooling.
