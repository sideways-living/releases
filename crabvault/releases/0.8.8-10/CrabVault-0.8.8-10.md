# CrabVault beta 0.8.8

This signed beta installer includes the current Apple workflow for encrypted
vaults, profile and contact management, identity documents, payment cards,
banking modules, OCR correction learning, backups, and relay transfers.

This build also enables signed Sparkle updates from the public CrabVault release
feed. Existing vault data remains in place when the application is replaced or
updated.

Before installing a beta, keep a current encrypted backup and recovery kit in a
separate safe location.
