# IVO Evidence Releases

This directory contains the public Sparkle update feed and signed Mac beta archives for IVO Evidence.

- `appcast.xml` is the feed embedded in current application builds.
- `release-notes/` retains the notes shown for each published version.
- `releases/<version>/` contains the immutable application ZIP, checksum file and release notes.

No case data, evidence, logs, credentials, source code or Sparkle private signing keys belong in this repository.
