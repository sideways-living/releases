# CrabVault for Mac

Signed and notarised CrabVault installers and Sparkle metadata are stored here.

- Current feed: `appcast.xml`
- Immutable installers: `releases/VERSION-BUILD/`
- Release tags: `crabvault-vVERSION-BUILD`

This directory contains no CrabVault source code, signing keys, credentials, or user vault data.
